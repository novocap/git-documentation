## Próximamente

Ejercicios paso a paso, en orden de complejidad creciente:

1. **Primer commit**: crear un repositorio local, hacer un cambio y commitearlo.
2. **Resolver un conflicto**: simular un merge conflict y resolverlo.
3. **Pull Request con code review**: abrir un PR en GitHub y aplicar
   sugerencias de revisión.
4. **Branch protection**: configurar reglas de protección en una rama.
