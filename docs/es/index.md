# Guía de aprendizaje de Git y GitHub

:wave: Bienvenido al repositorio de guía de aprendizaje y práctica con
Git y GitHub.

Este sitio es el espejo renderizado de la documentación mantenida en el
repositorio [novocap/Novocap.Learning.Git.Docs][repo]. La documentación se
publica en **dos idiomas**:

- **Español** (idioma por defecto).
- **English** (traducción paralela).

[repo]: https://github.com/novocap/Novocap.Learning.Git.Docs

## ¿Qué vas a encontrar?

Una guía paso a paso para configurar el entorno, dominar los fundamentos
de Git, contribuir a proyectos en GitHub y aplicar buenas prácticas con
herramientas asociadas (SSH, GPG, Markdown e IDEs).

!!! tip "Cambiar de idioma"
    Usá el selector en la esquina superior derecha para alternar entre
    español e inglés. Toda la navegación se traduce de forma sincronizada.

## Cómo contribuir

La documentación acepta contribuciones vía Pull Request. El flujo completo
está documentado en [`AGENTS.md`](https://github.com/novocap/Novocap.Learning.Git.Docs/blob/main/AGENTS.md)
(en español) e incluye:

1. Convención de commits con **gitmoji**.
2. PRs siempre en **español** y en estado **Draft**.
3. Mirror ES/EN sincronizado.
4. Reglas duras del repositorio.
