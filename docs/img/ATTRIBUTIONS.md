### Atribución sugerida

Cuando reutilices estas imágenes en otro contexto, mencioná:

> Captura de pantalla de GitHub Docs, usada bajo [CC BY
> 4.0](https://creativecommons.org/licenses/by/4.0/).

## Política de uso

Estas imágenes se incluyen con el único propósito de documentar
visualmente los flujos de GitHub explicados en este repositorio. Si
GitHub actualiza o retira alguna de estas imágenes, este repositorio
debe seguir el [principio de reagrupación por substitución][reorg] y
reemplazarlas localmente o eliminarlas en una PR de limpieza.

[reorg]: https://en.wikipedia.org/wiki/Replacement_clause

## Cómo contribuir con nuevas imágenes

Si agregás una imagen en este directorio, agregá una entrada a la
tabla correspondiente en este archivo con:

1. **Archivo local** y URL original.
2. **Página de origen** (la página de docs donde aparece).
3. **Licencia** (idealmente CC BY 4.0 o compatible).
4. **Atribución sugerida** si la licencia lo requiere.

## Aviso sobre imágenes obsoletas

Las 47 capturas eliminadas en el commit que precede este archivo eran
capturas de pantalla de la UI de GitHub y VSCode de 2019, tomadas
directamente por los autores originales del repositorio
([novocap](https://github.com/novocap)) y del ejemplo del libro [Pro
Git v2](https://github.com/progit/progit2-es). No tenían atribución
explícita en el repositorio original, pero tampoco infringían
ninguna licencia conocida. Se eliminaron porque la UI mostrada ha
cambiado significativamente desde entonces.
